Find and fix messy text with regular expressions

Python’s find and replace need the exact text, and a regular expression describes its shape. Find, extract and fix text by pattern in a Colab notebook.

Why it matters

Messy text rarely arrives in one exact form. Phone numbers come as 215-555-0134 and as (215) 555 0134, and dates, order numbers and email addresses sit inside longer lines of logs, forms and exports.1 Python’s find and replace need the exact text, so cleaning that kind of data with them turns into loops full of conditions.

A regular expression describes the shape of the text instead, such as four digits in a row or a word at the start of a line, and Python’s re module finds, extracts, splits or replaces everything that fits.1 Ask whoever cleans your text data to show the patterns they used, because a pattern that matches more or less than intended changes the data without an error.

What you will do

The notebook works on short log lines, contact text and a scrap of HTML, and every cell’s output is saved in it.1

  1. Search for a shape with re.search, and test the result before using it. A pattern that matches nothing returns None instead of raising an error.1
  2. Write every pattern as a raw string. In an ordinary string \b is a backspace, so re.findall("\bweb", log) returns an empty list with no warning, while r"\bweb" finds the word.1
  3. Build patterns from \d, \w and \s, your own character classes in square brackets, and counts such as + and {4}.1
  4. Pull fields out with named groups, turning a log line that starts 2026-09-04 10:22:31 ERROR into its date, level and message.1
  5. Make a greedy pattern lazy. On <b>bold</b> and <i>italic</i>, the pattern <.*> returns the whole string as one match, and <.*?> returns the four tags.1
  6. Read the three errors the notebook runs on purpose: calling .group() on no match, a repeat with nothing in front of it, and a parenthesis that is never closed.1

The quickest check of a pattern is the notebook’s own. It marks every match inside the original text, so you can see what the pattern caught and what it left alone.1

text = "Call 215-555-0134 or 610-555-9876 before 2026-09-04"
print(re.sub(r"\d{3}-\d{3}-\d{4}", r"[\g<0>]", text))
# Call [215-555-0134] or [610-555-9876] before 2026-09-04
